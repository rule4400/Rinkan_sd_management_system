# 記録班 SDカード管理システム

映像制作チーム（記録班）が、撮影で使用する SD カードの**持ち出し・予備・提出**を
追跡・管理するための Web アプリケーションです。
SD カードの紛失やトラブル発生時に、「いつ・誰が・どのカードで・どのシーンを撮ったか」を
即座に追跡できることを目的としています。

- スマホ（撮影現場）から使う **登録画面**
- PC から使う **管理者ダッシュボード**
- LAN 内での運用を基本としつつ、**無料の範囲でインターネット越しの操作**にも対応

## 技術スタック（推奨）

| 領域 | 採用技術 | 理由 |
| --- | --- | --- |
| フロント/バック | Next.js (React + TypeScript) | 単一コードベースでフルスタック・レスポンシブ対応が容易・自前ホスト可 |
| UI | Tailwind CSS | モバイルファーストのレスポンシブを低コストで実現 |
| DB | SQLite + Prisma ORM | ファイル1個で完結・無料・バックアップはコピーのみ。将来 Postgres へ移行可 |
| 認証 | パスワード（管理者）＋ 端末/チーム passphrase（利用者） | 用途に応じた段階的な保護 |
| 公開 | LAN 自前ホスト ＋ Cloudflare Tunnel（無料） | ポート開放不要・HTTPS 自動・完全無料 |

詳細・代替案は[システム設計書](docs/system-design.md)を参照してください。
